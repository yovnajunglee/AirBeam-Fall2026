# 🌍 AirBeam Fall 2026

Welcome, Air Quality Explorers!

This is our class data hub for **PM2.5 air quality measurements** collected using AirBeam sensors.

Every measurement tells a story about the air around us on campus. By contributing your data, you're helping our class investigate air quality, discover patterns, and better understand the environment where we live and study.

**Your Step:** Collect data, name your files correctly, and upload them to our shared repository!

---

## Step 1: Collect Your Data

Use your AirBeam sensor to collect PM2.5 measurements as instructed in class.

Before uploading, make sure your data has been saved as a `.csv` file.

## Step 2: Name Your File Correctly

Choose the naming format that matches the type of data you are uploading.

### A. Individual Data Sessions

For each individual data collection session, use:

`PM25_<name>_<daterecorded>_<session_number>.csv`

**Examples:**

- `PM25_yovnajunglee_20261023_1.csv`
- `PM25_yovnajunglee_20261023_2.csv`
- `PM25_yovnajunglee_20261021_1.csv`

**Remember:**
- Use lowercase letters for your name, without spaces.
- Use the date the data was collected (YYYYMMDD).
- If you collect data multiple times on the same day, increase the session number (1, 2, 3...).

### B. Compiled Data (Multiple Dates)

If you combine data collected across multiple dates into one file, use:

`PM25_<name>_<datestart>_<dateend>.csv`

**Example:**

`PM25_yovnajunglee_20261021_20261023.csv`

Use the first and last dates included in your compiled dataset.

### C. Compiled Data (Same Day)

If you combine all your individual sessions from the same day into one file, use:

`PM25_<name>_<daterecorded>_COMBINED.csv`

**Example:**

`PM25_yovnajunglee_20261023_COMBINED.csv`

**Important:** Use `COMBINED` to distinguish a compiled dataset from an individual session. Do not upload duplicate copies of the same measurements.

## Step 3: Upload Your Data

Ready to contribute? Follow these steps:

1. Open this GitHub repository.
2. Navigate to the `data/` folder.
3. Click **Add file**, then select **Upload files**.
4. Select or drag your `.csv` file into the upload area.
5. Double-check that your filename follows the correct naming format.
6. Scroll down and click **Commit changes** to save your contribution to the repository.

**Important:** All class data files belong in the `data/` folder. Please do not upload CSV files to the main repository folder.

## Step 4: Verify Your Upload

Don't leave your Step incomplete until you've confirmed that your data is in the repository!

After uploading your file:

1. Return to the main page of this GitHub repository.
2. Open the `data/` folder.
3. Look for your uploaded CSV file in the file list.
4. Check that your filename appears exactly as expected.
5. Click on the filename to open it.
6. Confirm that your data is visible and that the file contains the expected measurements.

**Step accomplished!** If you can see your file in the `data/` folder and open it successfully, your upload was successful!

**Can't find your file?**

- Refresh the GitHub page.
- Make sure you are looking inside the `data/` folder.
- Check that you completed the **Commit changes** step.
- If the file is still missing, try uploading again or ask for help.
